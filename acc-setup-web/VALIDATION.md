# Hasil pemeriksaan — 6 Oktober 2026

- Node 24.14.0; dependency stabil dikunci pada `package-lock.json`.
- `npm run typecheck`: lolos.
- `npm run format:check`: lolos.
- `npm test`: **108 tes lolos**. Termasuk pemeringkatan suhu/metadata/versi/BoP, compound dry/wet/damp/drying, cakupan profil, koreksi rentang/titik, pembulatan, target 60 psi, gate stabil/insiden/perubahan kondisi, run berikutnya, deviasi, snapshot dan migrasi v1–v2. Seluruh 1.602 record dan 68 nilai/record juga dicocokkan terhadap snapshot, termasuk urutan roda, ID, nol sah dan status konversi. Integritas 38 topik belajar diperiksa: ID unik, semua 68 parameter punya satu pelajaran dan dapat dicari lewat label ACC, alias, referensi antar topik, sumber, serta registry visual/eksperimen. Contoh tekanan, fuel, per, damper, aero, rasio kemudi dan rake diuji terhadap satuan dan batas input, termasuk koma desimal/kosong/invalid.
- `npm run build`: lolos. Snapshot mentah tidak masuk bundle/runtime; data tersedia sebagai katalog dan 54 file per mobil.
- `npm run test:e2e`: **56 tes lolos**, 28 alur pada masing-masing viewport desktop dan mobile Chromium. Mencakup seluruh alur setup sendiri tanpa katalog: kondisi → fuel → empat roda → simpan → run berikutnya → evaluasi → reload. Termasuk target ekstrem ditolak saat simpan, gate kualitas, versi berubah, ketidakpastian drying, migrasi browser v1 dan pemeliharaan key lama, serta pencarian, favorit, clipboard, backup/merge, file rusak, kegagalan asset/storage, keyboard dan overflow layout. Fitur belajar diuji melalui seluruh kategori, pencarian alias, hash/reload/back, tujuh eksperimen dan reset, bantuan parameter/kamus, satu dialog, kembali ke sumber yang sama, Escape/pengembalian fokus, serta draft fuel yang tetap sama setelah bantuan dan perpindahan tab.
- Screenshot desktop/mobile ditinjau: `tests/screenshots/*-search.png`, `*-result.png`, `*-practice.png`, `*-recommendation.png`, `*-pressures.png`, `learning-index-desktop.png`, `learning-camber-desktop.png`, `learning-camber-mobile.png`, dan `learning-pressure-mobile.png`.
- Development **127.0.0.1:5173** tersedia. Playwright memakai preview terpisah **127.0.0.1:4173**, sehingga tidak perlu menghentikan development. Kedua port menggunakan penyimpanan browser terpisah.
- Tidak ditemukan request font/CDN/API eksternal selama alur pencarian dan hasil. Tes belajar memblokir request internet dan membuat katalog gagal dimuat; materi, SVG dan tujuh eksperimen tetap berfungsi. Diagram memiliki nama aksesibel, kontrol range bekerja dengan keyboard, reduced motion menonaktifkan transisi, dan halaman 360 px tidak overflow. Video berupa tautan opsional yang ditandai perlu internet dan dibuka di tab baru.

Yang belum diuji: Safari, Firefox, perangkat mobile fisik, dan penggunaan berkendara langsung di ACC. Viewport mobile menggunakan emulasi Chromium. Kelengkapan data dan lolos tes aplikasi tidak membuktikan setup cocok untuk patch/BoP tertentu atau menghasilkan waktu lap tercepat.

Data snapshot mengacu pada ACC PC 1.10.4, diperiksa 1 Oktober 2026. **326/1.350 pasangan mobil–sirkuit** punya record spesifik; cakupan kondisi/sesi/karakter lebih terbatas lagi. Tidak ada record yang diberi label kompatibilitas patch terverifikasi. Parameter maupun metadata yang belum tersedia tetap ditandai jelas.

Profil slick DHF menggunakan acuan historis 26–27 psi era v1.9 dan wet menggunakan acuan publik 30–31 psi. Keduanya dibatasi cakupan awal dan ditampilkan sebagai acuan yang perlu diuji. Model/versi di luar cakupan meminta target manual dengan sumber. Tidak ada koefisien suhu universal atau prediksi peningkatan waktu lap. Target manual 20–40 psi dan cold/hot/hasil 10–50 psi merupakan batas kewajaran aplikasi, bukan batas slider resmi mobil.

Penyimpanan/backup schema v2 mempertahankan setting aktual dan snapshot rekomendasi. Migrasi v1 menjaga favorit/catatan, target manual dan hasil historis, sambil menandai konteks/kualitas baru belum diketahui. Impor snapshot memvalidasi hitungan dan kualitas tanpa mengganti bukti lama dengan katalog baru. Bila localStorage gagal, state sesi tetap bisa diekspor.

Belajar Setup tidak mengubah schema v2 atau menyimpan progres/checklist/eksperimen sebagai latihan. Materi memisahkan prinsip fisika, arsip ACC menurut versi, dan hipotesis pengujian. Model alignment tidak meramalkan grip; koefisien per/damper serta acuan gaya aero hanya ilustrasi. Sumber primer Kunos, produsen, dan laporan pengujian langsung dicantumkan per topik. Acuan tekanan menggunakan profil app yang ada dengan status bukti serta cakupan tetap terlihat.

Screenshot asli tersedia untuk seluruh 38 topik, menggunakan sembilan aset lokal yang dideduplikasi (478.695 byte). Registry memuat dimensi asli, pembuat, tautan artikel/file, konteks, status arsip, dan bukti versi. Versi 1.7.7 pada Electronics terlihat di gambar; 1.10.2 pada replay Ferrari 296 GT3 hanya menurut artikel. Versi/model/platform yang tidak disebut tetap tidak diketahui. Setiap gambar asli diperiksa sebelum dipakai; seluruh panel topik dan potongan detail ditinjau pada hasil QA desktop/mobile 360 px di `tests/screenshots/acc-media/`. Penanda dibuat lewat React/SVG, file sumber tidak diedit.

Tambahan 12 tes unit memeriksa header WebP/JPEG terhadap dimensi registry, keberadaan/deduplikasi aset, atribusi, 38 referensi topik, pemetaan 68 parameter, koordinat penanda/detail dan cakupan crop. Tambahan delapan tes browser memeriksa setiap penanda pada seluruh topik, pemilihan crop, zoom 100–300%, area gulir keyboard tanpa overflow halaman, sembunyikan penanda, reload hash, pemilihan roda asal dalam bantuan, satu dialog, sumber/fokus/draft yang sama, serta kegagalan gambar. Semua topik dan gambar dimuat dengan request internet diblokir serta katalog 503; tidak ada request eksternal.

Nomor yang berdekatan diposisikan pada sisi berbeda agar mudah dikenali di HP. Detail gambar memperjelas field, sedangkan angka sumber tetap contoh arsip: LAST READINGS nol bukan hasil pengukuran; fuel per lap dan front aero variation merupakan informasi; splitter pada capture tidak tampak dapat diatur. Tekanan target dan kualitas pengukuran tetap mengikuti profil/aturan app. Screenshot tidak memvalidasi perilaku semua mobil atau patch. Tidak ada perubahan schema personal/backup v2.
